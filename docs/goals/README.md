# 목표 — 복리 계획의 기준 (정본)

`/goals` 화면의 상수(`src/lib/compound-plan.ts`)는 이 표를 코드로 옮긴 것이다. 랩 회차가 다시 돌면
**여기를 먼저 고치고** 상수를 따라 맞춘다. 출처는 전부 이 저장소 안에 있다.

## 1. 목표의 실제 크기

1억 원 = **71,942 USD** (환율 1,390 가정). 시작 100$, 매월 말 납입, 월 복리.

| 기간 | 납입 100$ | 납입 150$ | 납입 200$ | 납입 0 |
|---|---|---|---|---|
| 3년 | 월 13.11% | 월 11.65% | 월 10.55% | 월 20.05% |
| 5년 | 월 6.56% | **월 5.65%** | 월 4.98% | 월 11.59% |
| 7년 | 월 4.10% | **월 3.44%** | 월 2.94% | 월 8.15% |
| 10년 | 월 2.44% | **월 1.96%** | 월 1.60% | 월 5.64% |

월수익률별 도달 개월(납입 150$): 월 2% → 119 · 3% → 92 · 5% → 66 · 10% → 41.
환산(기하): 월 2% = 주 0.46% = 거래일(21) 0.09% = 연 26.8% · 월 5% = 주 1.13% = 일 0.23% = 연 79.6%.

산식: `FV = P(1+r)^n + C((1+r)^n − 1)/r`. 테스트가 표의 값을 고정한다(`compound-plan.test.ts`).

## 3. 계획 β / 목표 α (기본안)

| | 계획 β (반드시) | 목표 α (도전) |
|---|---|---|
| 월수익률 | +2.0% | +5.0% |
| 정지선 (고점 대비 월 낙폭) | −20% — 닿으면 그 달 중단 | 같음 |
| 거래당 리스크 | ≤ 2% | ≤ 3% |
| 레버리지 상한 | 5배 (상수) | 5배 (상수) |
| 1억 도달 (납입 150$) | 119개월 ≈ 10년 | 66개월 ≈ 5.5년 |

β 2%: 정지선 안에 머무는 구성의 실측(2.04%)과 선배님 산식(2.84%) 사이 아래쪽. α 5%: 랩 상한이며
낙폭 −40%를 각오하는 값 — α를 달성해도 정지선 규칙이 β를 이긴다. 정지선 −20%는 선배님 20년 불변 숫자.
레버 5배: 복리 회차에서 10배 이상은 1,944설정 중 통과 0건.

값은 `goals` 표(북별, `period = month`)에 %로 저장한다: `return_pct` · `max_drawdown_pct`(양수 크기) · `risk_per_trade_pct`.

## 4. 단계와 승격·강등

| 단계 | 자금 | 승격 조건(전부) |
|---|---|---|
| 0 검증 | ~1,000$ | 3개월 연속 월 기하 > 0 · 정지선 미접촉 · 거래 ≥30건 |
| 1 축적 | 1,000~5,000$ | 6개월 연속 정지선 미접촉 · 분기 기하 > 0 · 켈리 양수 |

## 5. 이번 달 판정

성과 곡선(입출금 제외, `buildEquityCurve().performance`)에서 잰다 — 잔액 곡선으로 재면 납입이 수익으로
보인다. 월 낙폭의 고점은 **달 시작값**에서 출발한다(누적 MDD는 대시보드가 말한다).
순서: 정지선 접촉 → α → β → 양수 → 음수. 실현 거래가 없는 달은 판정하지 않는다.
판정은 표시일 뿐 주문을 막지 않는다.

## 6. 출처 갱신 규칙

- 랩 회차가 새로 돌아 상한·보수 값이 바뀌면 §2 와 `BENCHMARKS` 를 같이 고치고, 회차 번호를 적는다
- 켈리가 양수로 돌아서면 §2 의 켈리 행을 숫자로 바꾼다 — 그때가 단계 1 승격 조건 하나가 열리는 시점이다
- β/α 기본안(§3)은 사용자가 화면에서 바꾸면 표가 정본이고, 여기 값은 "처음 제안"으로 남는다
