# 고도화 로드맵 — 알려진 한계와 다음 단계

`data/` 에 쌓이는 decisions·trades·equity 로그가 이 로드맵의 원재료다.
순서는 위가 먼저 — 근거(데이터)가 모이는 것부터.

## 1. 전방 성적 대시보드 (데이터 20건부터)
- `data/trades-*.jsonl` 을 백테스트 원장 형식으로 집계: 승률·기대값·P/F·MDD를
  인샘플 수치와 나란히 — 승격 사다리 판정을 표로 자동화.
- 기존 도구 재사용: `scripts/backtest/` 의 리포트 템플릿 패턴.

## 2. 데모 검증에서 밝혀야 할 것 (코드 TODO)
- **같은 방향 병행**: OKX 롱숏 모드에서 gc+ob 동시 보유 시 포지션 합산 —
  브래킷은 `algoClOrdId` 로 분리했지만 실제 트리거·부분 청산 동작은 데모에서 확인 필요.
- **order-algo 상세 응답 필드 실측**: 청산 유형(`actualSide`)·체결가(`actualPx`)·상태 전이
  (live→effective)가 코드 가정대로인지 데모에서 최소 1회 목표·손절 체결로 확인.
- **증거금 캡 동작**: 레버 상한 10 고정 + 가용 증거금(잔고 90% − 사용분) 초과 시 명목 축소가
  실제 주문 수락/증거금 화면과 맞는지 — 특히 손절이 아주 좁아 lev=10인 진입.
- **시한 청산 경합**: 시한 도달 봉에서 손절·목표가 먼저 걸리는 경계 상황.

## 3. 체결 품질 (실효 비용 절감)
- 시장가 → **지정가(메이커) 진입 시도 후 N초 미체결 시 시장가 전환** — 표본 200 검토에서
  비용 절반이면 1시간봉 기준들이 표 안으로 들어온다.
- 체결가와 신호 봉 종가의 차이(슬리피지)를 trades 로그에 기록해 0.1% 가정을 실측으로 교체.

## 4. 기준 고도화 (전방 데이터로 검증 후 반영)
- ④ 신저가 이탈: 고정 2%/4% → **1.5×ATR 트레일** 전환 (백테스트 $110→$188, 표본 11건이라 보류 중).
- ①: 이평선 기울기·ATR 수축(횡보) 필터. ②③: SMA200 국면 필터(그리드에서 표본 부족).
- 펀딩비를 사이클마다 기록하고 기대값에 반영.

## 5. 인프라
- 상시 머신(미니PC/VPS) 이전 · 프로세스 감시(pm2 등) · 실패 알림(텔레그램/디스코드 웹훅).
- state 자동 백업. 월 1회 데이터 스냅샷을 원장 회차 문서로 커밋.

## 바꾸지 않는 것
- 판정 부등식·청산 폭·사이징 공식은 **전방 데이터가 근거를 만들기 전에는** 손대지 않는다.
  바꾸면 그 시점부터 다른 시스템이고, 승격 시계는 리셋된다 (`criteria.md` 가 정본).
