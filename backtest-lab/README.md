# backtest-lab — 월 10% 복리 도달 가능성 검증 (BTC · 4H 이하)

> 별도 실험실. `scripts/backtest/` 의 회차 원장과 **코드를 공유하지 않는다.**
> 비용·회계·청산 공식만 시리즈 관례를 따라 결과를 비교 가능하게 둔다.

---

## 0. 이 회차가 답하려는 것

**질문:** BTC를 4H·1H·15m 기술적 지표만으로 매매해서 **월 10% 이상을 복리로** 가져갈 수 있는가.

**목표치의 실제 크기 — 먼저 못 박는다.**

```
월 10% 복리 → (1.10)^12 − 1 = 213.8% CAGR
```

시리즈 11회차 누적 최고 성과는 **CAGR 48% · MDD −35% · MAR 1.39** (베이시스 회차, 게이트 6/6).
MAR(=CAGR/|MDD|)이 성과 품질의 상한이라면:

```
CAGR 213.8% ÷ MAR 1.39 = MDD −154%   → 수학적으로 파산
```

즉 **"기존 엣지에 레버리지만 얹어서 월 10%"는 불가능이 확정되어 있다.**
남은 경로는 셋뿐이고, 이 회차는 셋을 전부 측정한다.

| 경로 | 무엇을 늘리는가 | 이 회차의 축 |
|---|---|---|
| A. 엣지 품질 | 회당 기대값 | 미검증 지표군 전수 (31계열) |
| B. 거래 빈도 | 월 거래 수 | 15m·1H 재투입 + 병행 폭 확대 |
| C. 사이징 | 회당 베팅 크기 | 레버리지·리스크% 프런티어 |

**따라서 이 회차의 성공 정의는 "월 10% 달성"이 아니다.**
성공 = **월수익률–MDD–파산확률 프런티어를 정직하게 그려서, 10%가 어디에 있는지(또는 없는지) 확정하는 것.**

## 1. 사전 등록 (Pre-registration)

> 결과를 보고 기준을 고치면 그건 백테스트가 아니라 곡선 맞추기다.
> 아래는 **데이터를 보기 전에** 고정한다. 실행 후 수정 이력은 §7에 남긴다.

### 1-1. 데이터 창

| 봉 | 창 | 예상 캔들 | 워밍업 |
|---|---|---|---|
| 15m | 730일 | ~70,000 | 300봉 |
| 1H | 1,200일 | ~28,800 | 300봉 |
| 4H | 1,800일 | ~10,800 | 300봉 |
| 1D | 1,800일 | ~1,800 | (상위봉 정렬 전용) |

- 소스: OKX `BTC-USDT-SWAP` 확정봉(`confirm=1`)만.
- 펀딩: OKX 펀딩비 **실측 이력**(8시간 주기). 가정값이 아니다. — 시리즈 최초.

### 1-2. 비용 (전부 왕복 %)

| 항목 | 값 | 근거 |
|---|---|---|
| 테이커 왕복 | 0.10% | 시리즈 공통. **판정 기준.** |
| 메이커 왕복 | 0.07% | 진입 지정가 0.02 + 청산 시장가 0.05 |
| 슬리피지 | 0.02% | 15m 유동성 보수 가정, 왕복 |
| 펀딩 | 실측 | 롱 = 지불, 숏 = 수취(양수면 수취, 음수면 지불) |

### 1-3. 체결 규약 (시리즈 관례 그대로)

- 신호는 **봉 마감**에 판정, 진입은 **다음 봉 시가**.
- 한 봉에서 손절·목표 동시 터치 → **손절**로 본다(봉 내부 경로 미상).
- 전략당 동시 포지션 1개. 보유 중 신호는 스킵.
- 시한(maxHold) 도달 시 종가 청산. 창 끝에 열려 있는 거래(`open`)는 **통계에서 제외**.

### 1-4. 판정 게이트 — 부품 단계 (Phase 2·3)

전수 스윕은 조합이 많으므로 **다중검정 보정이 게이트의 핵심**이다.

| # | 게이트 | 임계 |
|---|---|---|
| G1 | 표본 | 15m ≥400 · 1H ≥250 · 4H ≥150 |
| G2 | 기대값 | 테이커+슬리피지+펀딩 기준 EV > 0 |
| G3 | Profit Factor | PF ≥ 1.15 |
| G4 | 구간 안정 | 창 3등분 중 **2구간 이상** 플러스 |
| G5 | 다중검정 | Benjamini–Hochberg **FDR q=0.10** 통과 |
| G6 | 아웃오브샘플 | IS(앞 65%) 선별 → **OOS(뒤 35%)에서 EV>0 · PF≥1.0** |

- G5 참고선: 조합 N개 전수에서 귀무 하 |t| 최대 기댓값 ≈ √(2·ln N).
  N≈4,500이면 **≈4.1** — 단일 t=2.0은 이 규모에서 아무 의미 없다. 리포트에 Bonferroni 임계도 병기.
- **G6를 통과하지 못한 부품은 Phase 4·5에 넣지 않는다.** 이것이 이 회차의 유일한 과적합 방어선이다.

### 1-5. 판정 게이트 — 복리 단계 (Phase 4·5)

주 가설: **"OOS 생존 부품의 병행 + 리스크 사이징으로 월 10% 복리."**

| # | 게이트 | 임계 |
|---|---|---|
| C1 | 월 중앙값 | 월수익률 중앙값 ≥ **10%** |
| C2 | 달성률 | 월 10% 이상인 달의 비율 ≥ 50% |
| C3 | 낙폭 | 봉 단위 MDD ≥ **−50%** |
| C4 | 청산 | 시뮬 기간 강제청산(liquidation) **0건** |
| C5 | 파산확률 | 블록 부트스트랩 1,000회에서 $100→$10 이하 도달 확률 ≤ 5% |
| C6 | OOS | OOS 구간에서도 C1~C4 유지 |

**C1~C6 전부 통과 = "월 10% 복리 가능" 확정. 하나라도 실패하면 실패로 보고한다.**
부분 통과 시에는 **완화된 목표(월 5% / 월 3%)에서 어디까지 통과하는지**를 같은 표로 병기한다.

## 2. 실험 축 (전수 설계)

### 2-1. 진입 신호 — 31계열 × 롱/숏 미러

시리즈에서 **이미 기각된 것을 다시 돌리지 않기 위해**, 미검증 지표를 대량 투입한다.
(★ = 이 저장소에서 처음 검증)

| 계열 | 신호 |
|---|---|
| 추세 | ema-cross · macd-cross · supertrend-flip ★ · adx-di-cross ★ · psar-flip ★ · ichimoku-tk ★ · aroon-cross ★ · vortex-cross ★ |
| 모멘텀 | rsi-revert · stochrsi-cross ★ · cci-revert ★ · williams-revert ★ · roc-thrust ★ · tsi-cross ★ · fisher-flip ★ · ultosc-revert ★ |
| 변동성 | bb-breakout · bb-revert · keltner-break ★ · donchian-break · ttm-squeeze ★ · atr-expansion ★ |
| 거래량 | obv-break ★ · mfi-revert ★ · cmf-flip ★ · vwap-reclaim ★ · volspike-cont |
| 구조 | inside-bar · big-bar · pivot-hh ★ · zscore-revert |

→ 31계열 × 2방향 = **62 신호**

### 2-2. 청산 기하 — 6종

| 키 | 손절 | 목표 | 성격 |
|---|---|---|---|
| x1 | 1×ATR | 1×ATR | 고승률·저손익비 |
| x2 | 1×ATR | 2×ATR | 균형 |
| x3 | 1.5×ATR | 3×ATR | 표준 1:2 |
| x4 | 2×ATR | 6×ATR | 와이드 (비용 상각) |
| x5 | 3×ATR | 9×ATR | 엑스와이드 |
| x6 | 2×ATR | 트레일 2×ATR | 추세 추종형 (샹들리에) |

### 2-3. 국면 필터 — 4종

f0 무필터 · f1 상위봉 정렬 · f2 저변동 선행 · f3 거래량 확장

### 2-4. 전수 규모

```
62 신호 × 6 청산 × 4 필터 × 3 봉 = 4,464 백테스트
```

### 2-5. 레버리지 축 (Phase 4)

- 사이징 A — **리스크 기반**: `L = min(Lcap, 리스크% ÷ (손절폭% + 비용%))` (시리즈 공식)
- 사이징 B — **고정 레버리지**: 1 · 2 · 3 · 5 · 7 · 10 · 15 · 20 ×
- 사이징 C — **분수 켈리**: f\* × {0.25, 0.5, 1.0}
- 강제청산: 유지증거금 0.5% 가정, `청산 임계 = 100/L − 0.5`, 거래 MAE로 판정. 청산 시 잔고 소각.

### 2-6. 복리 오버레이 (Phase 5)

base · throttle(낙폭 비례 리스크 축소) · regime(일봉 SMA200 게이트) · both

## 6. 알려진 한계 (리포트에도 그대로 싣는다)

1. **인샘플 상한** — 4,464개를 훑은 뒤의 최고값은 실전 기대값이 아니다. OOS 수치만 인용할 것.
2. **봉 내부 경로 미상** — 손절·목표 동시 터치를 손절로 처리해도, 15m에서는 실제 체결이 더 나쁠 수 있다.
3. **단일 자산·단일 거래소** — BTC-USDT-SWAP(OKX) 하나. 일반화 근거 없음.
4. **레짐 편중** — 창 안의 상승장 비중이 결과를 좌우한다. 구간 3등분으로 부분 완화할 뿐이다.
5. **청산 모델 단순화** — MAE 기준 판정. 실제 ADL·부분청산·증거금 추가는 모형에 없다.

## 8. 결과 요약 (2026-08-17 실행)

> 전체 수치는 `out/*.json`, 서술은 `out/report.html`.

**사전 등록 판정: 부품 게이트 6/6 통과 0 / 4,464. 복리 게이트 C1~C5 통과 0 / 288.**
**→ "BTC 4H 이하 기술적 지표로 월 10% 복리" 는 이 회차에서 기각.**

핵심 근거 넷:

1. **우연보다 약하다.** 4,428개 조합의 최대 t = **2.66**. 같은 수를 무작위로 뽑을 때 기대되는 최대 t는 **4.10**. 전수를 다 훑고도 우연이 만드는 수준에 못 미쳤다.
2. **비용 이전에도 없다.** 수수료·슬리피지·펀딩을 **0으로 두어도** 최대 t는 15m 2.78 · 1H 2.96 · 4H 3.31 로 여전히 귀무 기댓값(3.82) 아래다. "비용이 엣지를 먹었다"가 아니라 **먹을 엣지가 없었다.**
3. **워크포워드 8/8 전멸.** IS(앞 65%)에서 t=1.4~3.1로 뽑은 부품 8개가 OOS(뒤 35%)에서 **전부 EV 음수**. 선별 자체가 곡선 맞추기였다는 직접 증거.
4. **필요한 엣지의 크기.** 월 10%는 체결 27회/월에서 거래당 순수익 **0.35%**(관측 인샘플 최고치의 1.67배)를 요구하고, 그 엣지의 t는 **5.15**다. 관측 최대 2.66의 두 배.

부수 확인:
- **봉이 짧을수록 나쁘다** (EV>0 비율 15m 2.0% · 1H 14.6% · 4H 34.4%). 15m 4차 기각.
- **레버리지는 병목이 아니다.** 인샘플 최고 바스켓은 실효 1.67×면 월 10%에 닿는다. 병목은 엣지다.
- **월 중앙값은 목표 달성의 증거가 못 된다.** 인샘플 최고 설정은 월 중앙 **+11.9%**(C1·C2 통과)를 내면서 자산이 $1,364 → $56(**−96%**), 3.16년 최종 $109.
- **펀딩은 이 홀딩 길이에서 무시할 수준** (거래당 0.0001~0.0031%). 진짜 비용은 수수료+슬리피지 0.12%/거래.
- **신규 검증 18개 지표**(슈퍼트렌드·일목·PSAR·볼텍스·아룬·TSI·피셔·UO·CMF·MFI·OBV·VWAP·StochRSI·CCI·%R·ROC·켈트너·TTM) 중 게이트 통과 **0개**.
