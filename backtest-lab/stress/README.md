# 창 확장 · 워크포워드 · 스트레스 회차 — 사전 등록

> **작성 시점: 실행 전.** 아래 게이트는 결과를 보기 전에 고정한다.
> 실행 후 바꾼 것이 있으면 §6 변경 로그에 사후 변경임을 명시한다.

## 0. 묻는 것

14회차가 §12에 스스로 적어 둔 검증 항목을 그대로 집행한다.

> **14회차의 결론은 하락장을 겪지 않았다. 겪게 하면 남는가.**

14회차 창은 2023-06 ~ 2026-08(1,148일)이었다. 1H 부품이 2023-05부터라 거기서 잘렸고,
그래서 **2022 하락장이 통째로 빠져 있었다**. 그 창에서 매수보유는 +112%였다.
낙폭 게이트 C3(≤40%)은 하락장에서 시험된 적이 없다 — 그것이 14회차의 가장 큰 구멍이다.

이번 회차는 1H 부품을 버리고 **4H·1D 부품만 남겨 창을 4.75년으로 늘린다.**
그 창의 매수보유 최대 낙폭은 **−77.0%**(2022-11 저점)다.
부품이 14종에서 10종으로 줄어 분산이 약해지는 것은 이 실험이 치르는 값이다.

## 1. 무엇을 바꾸고 무엇을 고정하는가

| | 14회차 | 15회차 |
|---|---|---|
| 부품 | 14종 (1H 4종 포함) | **10종 (4H·1D만)** |
| 창 | 2023-06 ~ 2026-08 (1,148일) | **2021-11 ~ 2026-08 (약 1,730일)** |
| 하락장 | 없음 (매수보유 +112%) | **포함 (매수보유 최대 낙폭 −77%)** |
| 1D 캔들 | 랩 캐시 2021-09~ | **긴 것 2020-01~** (워밍업이 창을 잘라먹지 않게) |
| 게이트 C1~C6 | 사전 등록 | **그대로** — 잣대를 바꾸면 비교가 아니다 |
| 기법 · 레버리지 · 리스크 축 | 9 × 4 × 9 | **그대로** |

부품 묶음은 4H·1D 로 다시 짠다: 쿼드(4) · 검증계보6 · 베이시스2 · 혼합7 · 전체10.
**혼합7은 14회차 권고 구성(혼합9)에서 1H 부품 두 개를 뺀 것**이라 직접 대응된다.

## 2. 사전 등록 게이트 — 이번 회차가 새로 묻는 것

C1~C6(청산·파산확률·낙폭·MAR·벤치초과·구간안정)은 **14회차 정의 그대로** 쓴다.
그 위에 이번 회차의 판정 넷을 얹는다.

| 게이트 | 기준 | 왜 |
|---|---|---|
| **D1 창 확장 부호 유지** | 하락장을 포함한 창에서도 ① 통과 설정이 레버리지 3·5배에 몰리고 ② 리스크 3% 이하에 몰릴 것 | 14회차의 두 결론이 상승장 산물이었는지 가른다 |
| **D2 워크포워드** | 창 10등분 · 앞 3구간은 학습 전용 · 나머지 **7구간 중 MAR ≥ 1 이 5구간 이상** | 설정을 사후에 고르지 않고도 남는가. 선별 절차 자체를 시뮬레이션한다 |
| **D3 부품 탈락** | 최대 기여 부품 **2개를 동시에** 제거해도 월 기하 > 0 **그리고** 청산 0건 | 한두 부품이 죽었을 때 무너지는가 |
| **D4 체결 스트레스** | 슬리피지 0.02% → **0.06%(3배)** 에서 권고 구성이 청산 0 · 파산확률 ≤ 1% · MAR ≥ 1 | 비용 가정이 낙관이었는지 |

## 3. 워크포워드 절차 (D2) — 사전에 고정

1. 창을 시간으로 10등분한다.
2. 1~3구간은 **학습 전용**. 매매 성과로 세지 않는다.
3. 구간 k(4~10)마다: **1~(k−1)구간만 보고** 설정을 고른다.
   - 고르는 규칙: 학습 구간에서 청산 0 · 낙폭 ≤ 40% · MAR ≥ 1 을 만족하는 것 중 **MAR 최대**.
   - 만족하는 것이 없으면 MAR 최대를 고르고, 그 사실을 기록한다.
4. 고른 설정을 **구간 k 에만** 적용해 성과를 잰다. 이것이 OOS 다.
5. 7구간의 수익 배율을 연쇄해 워크포워드 자산 곡선을 만든다.

대조군 셋을 같은 구간에 함께 올린다:
- **매수보유** — 외부에서 주어진 기준
- **현행 라이브** (쿼드 · 고정비율 · 10배 · 리스크 10% · 동시 2) — 선별 없음
- **후행 상한** — 전 구간을 다 보고 고른 최선을 같은 OOS 구간에 적용. 도달 불가 상한선

## 4. 판정 기준

D1~D4 를 **전부** 통과하면 14회차 권고를 유지한다.
하나라도 실패하면 **실패한 항목이 이 회차의 결론**이며, 권고를 그만큼 좁힌다.

숫자 하나를 새로 최적화하는 회차가 아니다. **이미 낸 답이 버티는지 보는 회차다.**

## 5. 실행 순서

```
node stress/window.mjs   # 창 확장 그리드 → out/stress-window.json
node stress/wfa.mjs      # 워크포워드 → out/stress-wfa.json
node stress/robust.mjs   # 부품 탈락 + 체결 스트레스 → out/stress-robust.json
node stress/report.mjs   # → out/stress-report.html
```

봉 데이터는 `.cache/candles.json`(랩 공용), `scripts/backtest/.cache/spot-candles.json`(베이시스용
현물), `scripts/backtest/.cache/ten-candles.json`(긴 1D)을 쓴다. 새로 받지 않는다.

## 6. 사후 변경 로그

**게이트(§2)와 워크포워드 절차(§3), 판정 기준(§4)은 하나도 바꾸지 않았다.** 실행 후 추가한 것은 아래 셋뿐이다.

| # | 무엇을 | 왜 | 게이트에 영향 |
|---|---|---|---|
| 1 | 워크포워드 선별 규칙에 R2(월 기하 최대)·R3(무선별 균등) 추가 | 사전 등록한 것은 R1(MAR 최대)이고 D2 판정도 R1 로만 한다. R2·R3 는 "선별이 값을 하는가"를 재는 대조군이며 판정에 쓰지 않는다 | 없음 — D2 는 R1 기준 |
| 2 | 슬리피지 사다리에 0.04%·0.10% 추가 | 사전 등록은 0.06% 한 점이었다. 한 점만으로는 어디서 무너지는지 모른다 | 없음 — D4 판정은 0.06% 기준 그대로 |
| 3 | `runPart` 에 비용 오버라이드 인자 추가 (기본값 불변) | D4 를 돌리려면 슬리피지를 갈아끼워야 한다. 기본값을 그대로 둬 14회차 산출물은 재현이 유지된다(재확인함) | 없음 |

|---|---|---|

| **D4 체결 스트레스** | **통과** | 슬리피지 3배에서 권고 2종 모두 청산 0·파산확률 0%·MAR ≥ 1. 5배에서도 MAR 2.60→2.30 |

### 세부

- **창**: 2021-11-22 ~ 2026-08-12 (1,724일). 매수보유 총 +8.97% · 월 0.15% · **최대 낙폭 −73.38%**.
  14회차 창(1,148일)의 매수보유는 +111.77%였다 — 같은 자산의 같은 기간에서 상승 구간만 잘라 본 셈이었다.
- **현행 라이브(쿼드·고정비율·10배·리스크10%·동시2)**: 월 **−7.89%** · 낙폭 **−99.16%** ·
  강제청산 3건 · 파산확률 **94.5%** · 게이트 0/6. 구간 3등분 −21.84 / 0 / 0 —
  **첫 구간에서 사실상 끝나고 이후는 남은 자본이 없다.**
- **묶음**: 통과 103건 중 베이시스2가 99건, 전체10이 4건. **쿼드 · 검증계보6 · 혼합7 은 0건.**
  14회차 권고 구성(혼합9)의 4H·1D 판(혼합7)이 이 창에서는 하나도 통과하지 못한다.
- **부품 기여 뒤집힘**: 14회차 최대 기여자였던 r5(러너)가 이 창에서는 거래당 −0.19% · 누적 −43.1%로
  **빼는 편이 나은 짐**이다. bzc 가 1위 기여자로 올라섰고, **bzc 를 빼면 MAR 2.60 → 0.17**.
- **자금 기법**: 두 창 모두에서 MAR 차 부호를 지킨 것은 **변동성 타깃(m4, t 9.25→4.85)과
  낙폭 스로틀(m5, t 6.50→4.98)뿐**이다. 14회차 복리 부문 1위였던 1/4 켈리는 t +3.80 → **−4.69**로 뒤집혔다.
  고정 금액도 +7.85 → −2.70으로 뒤집혔다. CPPI 는 두 창 모두 나쁘다.
- **워크포워드**: 게이트는 실패했지만 연쇄 자산은 R1 $549 · 무선별 $210 · 매수보유 $231 · 후행 상한 $571.
  **선별이 작동하며 상한의 96%에 도달한다.** 게이트가 실패한 이유는 172일 구간에서 MAR 을 재면
  분모(낙폭)가 회복될 시간이 없기 때문이다 — **기준을 잘못 등록한 쪽이 나다.**

### 이 회차가 좁힌 것

| 항목 | 14회차 권고 | 15회차 이후 |
|---|---|---|
| 레버리지 상한 3·5배 | 권고 | **유지** |
| 리스크 3% 이하 | 권고 | **유지** |
| 자금 기법 = 1/4 켈리 | 권고 | **철회** → 변동성 타깃 · 낙폭 스로틀만 |
| 부품 = 혼합 9 (분산이 실재) | 권고 | **철회** — 사실상 베이시스가 시스템 |
| 체결 가정 | 테이커 0.10 + 슬리피지 0.02 | **여유 있음** (5배까지 견딤) |

### 남은 순환 논리

bzc·bzf 는 12회차가 **바로 이 창에서** 발굴했다. 워크포워드는 *설정* 선별이 OOS 에서 작동함을
보였을 뿐, *부품* 선택이 OOS 라는 것은 보이지 못했다. **다음 회차 1순위는 베이시스의 창 밖 검증**이다.
