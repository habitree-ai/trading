# 비대칭 페이오프 회차 — 사전 등록

> **작성 시점: 스윕 실행 전.** 아래 게이트는 결과를 보기 전에 고정한다.
> 실행 후 바꾼 것이 있으면 §6 변경 로그에 사후 변경임을 명시한다.

## 0. 묻는 것

> **손실은 하방으로 고정하고, 수익은 위로 열어두는 설계가 단기봉에서 성립하는가.**

이전 11회차가 답하지 못한 이유는 데이터가 아니라 **우리(cage)** 였다.
`lib/engine.mjs` 의 청산 6종 중 5종이 고정 목표가였고, `maxHold` 가
15m 3일 · 1H 5일 · 4H 10일로 묶여 있었다. **러너가 존재할 수 없는 구조에서
"수익을 길게 가져가는가"를 물은 적이 없다.** 이번 회차는 그 우리를 여는 것이 실험 본체다.

바뀌는 것 셋:
1. **상방 개방** — 고정 목표가를 기본 제거(대조군 C0만 유지).
2. **보유 개방** — `maxHold` 를 15m 20일 · 1H 30일 · 4H 90일로(기존의 6~10배).
3. **포지션 가변** — 부분익절(줄임)·피라미딩(늘림)을 같은 회계로 다룬다.

## 1. 사전 등록 게이트

판정 대상은 (봉 × 진입계열 × 방향 × 필터 × 기획) 조합이다.

| 게이트 | 기준 | 왜 |
|---|---|---|
| **G1 표본** | n ≥ 15m 250 · 1H 150 · 4H 100 | 러너는 보유가 길어 거래 수가 준다. 기존(400/250/150)보다 낮추되 **실행 전에** 명시한다 |
| **G2 기대값** | 비용·펀딩 차감 후 EV > 0 | 총이익이 아니라 순이익 |
| **G3 비대칭 실현** | 페이오프(평균이익 ÷ \|평균손실\|) ≥ 2.0 | "수익을 길게"가 말이 아니라 수치로 나타나야 한다 |
| **G4 하방 고정** | 손실 거래 중 \|순손실\| > 1R × 1.25 인 비율 ≤ 5% | **이 회차의 핵심 주장을 실측한다.** 1.25배 여유는 왕복 비용(0.12%)과 갭 |
| **G5 유의성** | 단측 t ≥ 2.0 **그리고** BH-FDR(q=0.10) 통과 | 672조합 다중검정. 귀무 최대 t ≈ √(2·ln n). 실측 501개 기준 3.53 |
| **G6 안정성** | 창 3등분에서 2구간 이상 EV > 0 | 한 구간이 전부를 만들면 기각 |
| **G7 대조 우위** | 같은 진입의 대칭 대조군(C0)보다 EV **와** 페이오프가 모두 높을 것 | 비대칭 설계 자체의 기여를 분리한다 |

### 게이트로 삼지 **않는** 것 — 그리고 그 이유

**꼬리 의존도**(상위 5% 거래를 빼면 EV가 음수가 되는가)는 측정하되 게이트로 쓰지 않는다.
비대칭 설계는 정의상 소수의 큰 승리로 먹고산다 — 꼬리 의존을 실격 사유로 삼으면
질문 자체를 부정하는 것이 된다. 대신 **공시 수치**로 전면에 낸다. 판단은 사용자가 한다.

## 2. 대조군 — 이것들을 못 이기면 기획은 의미가 없다

| 대조 | 내용 |
|---|---|
| **C0 대칭 고정기하** | 손절 1.5N · 목표 3N. 이전 11회차가 써 온 패러다임 |
| **C1 랜덤 진입** | 같은 청산 설계 + 무작위 진입(봉당 균등, 실제 신호 수 일치). 성과가 **청산 설계만으로** 나오는지 본다 |
| **C2 매수보유** | 같은 창의 BTC 무레버리지 |

## 3. 실험 축

- **봉**: 15m · 1H · 4H (단기봉 한정. 1D는 상위봉 필터로만 사용)
- **진입 8계열**: inside-bar · donchian-break · big-bar · pivot-hh · supertrend-flip · ttm-squeeze · macd-cross · ema-cross
- **방향**: long · short (숏은 롱의 기계적 미러 — 숏만 튜닝하면 그 자체가 과적합)
- **필터**: f0 무필터 · f1 상위봉 EMA 정렬
- **기획 5 + 사후 추가 1 + 대조 1**: P1 샹들리에 러너 · P2 터틀 러너(피라미딩) · P3 절반익절 러너 · P4 데드머니 컷 러너 · P5 2단 래칫 러너 · P6 상한고정 피라미딩(사후) · C0
- 총 3 × 8 × 2 × 2 × 7 = **672 조합** (P6은 사후 추가 — §6)

## 4. 비용·체결 규약 (이전 회차와 동일 — 비교 가능성 유지)

- 테이커 0.10% + 슬리피지 0.02% = 왕복 0.12%. **피라미딩은 유닛 수만큼 비용도 곱한다.**
- 펀딩은 OKX 실측(검증) + Binance 프록시(전 구간), 보유 기간 실측 누적.
  **러너는 보유가 길어 펀딩이 실질 비용이 된다 — 이 회차에서 처음으로 유의미해진다.**
- 신호는 봉 i 마감 판정, 진입은 i+1 시가. 손절·목표 동봉 충돌 시 손절 우선.
- 갭으로 스톱을 넘어가면 시가 체결(스톱 가격 체결은 낙관이다).

## 5. 실행 순서

```
node asym/selftest.mjs    # 엔진 자체 검사 7종 — 실패 시 중단
node asym/sweep.mjs       # 672조합 + 랜덤 대조 → out/asym.json
node asym/controls.mjs    # 창 통제 · 리스크 밴드 → out/asym-controls.json
node asym/thirds.mjs      # 4H 구간 3등분 → out/asym-thirds.json
node asym/detail.mjs      # 곡선 · R분포 · 표본 원장 → out/asym-detail.json
node asym/report.mjs      # → out/asym-report.html
```

봉 데이터는 상위 폴더의 `.cache/candles.json`(12회차 공용)을 그대로 쓴다. 새로 받지 않는다.

## 6. 사후 변경 로그

**아래 5건은 전부 스윕 결과를 본 뒤에 추가·수정한 것이다.** 게이트 자체는 하나도 바꾸지
않았고(§1 원문 유지), 추가된 것은 측정 지표와 통제 실험이다. 그래도 "결과를 보고 나서
움직였다"는 사실은 남으므로 전부 여기 적는다.

| # | 무엇을 | 왜 | 게이트에 영향 |
|---|---|---|---|
| 1 | **초과율 분해** — `breachGrossRate`(비용 전) · `costOverR` 추가 | G4가 "시장이 스톱을 뚫었는가"와 "비용이 1R보다 큰가"를 구분하지 못했다. 15m의 1R이 왕복비용(0.12%)보다 작을 수 있어 이 구분 없이는 하방 고정의 성패를 말할 수 없다 | 없음 — G4는 사전 등록대로 순손익 기준 유지. 분해는 공시 수치로만 |
| 2 | **P6 상한고정 피라미딩 추가** | P2의 갭·증량 초과 43.5%·최악 −9.25R을 확인한 뒤, "증량하되 총 하방을 1R로 묶으면?"이 자연스러운 다음 질문이 됐다. 사용자 요구 문장을 문자 그대로 만족하는 설계 | 조합 576 → 672. FDR 대상이 늘어 검정력은 오히려 보수적으로 이동 |
| 3 | **짝지은 비교 추가** (`planPaired` · `pairedByTf`) | 조합 간 이질성 때문에 풀링 t가 오염된다. 같은 (진입 × 방향 × 필터)에서 청산만 바꿔 짝지으면 진입의 좋고 나쁨이 상쇄된다 | 없음 — G7의 집계판. G7 자체는 사전 등록대로 조합 단위 |
| 4 | **통제 실험 2종** (`controls.mjs`) — 창 통제 · 리스크 밴드 | 4H 우위가 창(1,750일) 때문일 수 있었다. 그리고 "비용이 1R을 먹으면 1R을 넓히면 되지 않나"에 답해야 했다 | 없음 — 둘 다 선별 없는 전량 풀링 |
| 5 | **구간 3등분 재검정** (`thirds.mjs`) | 누적 곡선에서 P4가 +517% → +41%로 되돌아오는 것이 보였다. "한 시기가 전부를 만들었는가"를 묻지 않을 수 없었다 | 없음 — G6의 세분판. **결과적으로 리포트의 순위를 바꿨다**(P6·P4가 3구간에서 역전) |

**5번이 이 회차에서 가장 중요한 사후 조치다.** 사전 등록한 G6은 "3구간 중 2구간 이상 EV>0"이라
느슨했고, 그 기준으로는 P6이 통과한다. 구간별로 *대조군 대비 차이*를 다시 재고 나서야
최근 19개월의 부호 역전이 드러났다. 다음 회차에서는 **"세 구간 모두 대조군 우위"** 를
사전 등록 게이트로 올려야 한다.

## 7. 결과 요약 (실행 후)

- 조합 **672**개 중 전 게이트 통과 **0건**. G5(t≥2 + BH-FDR)는 단 한 건도 통과하지 못했다
  (표본 통과 501개의 최대 t = 1.79, 귀무 기대 3.53).
- **하방 고정은 성립한다.** P2(무제한 증량)를 뺀 전 기획에서 가격 손절이 뚫린 거래 0%.
  뚫은 것은 비용이다 — 1R의 5.7%(4H) ~ 28.5%(15m).
- **봉이 결론을 가른다.** 4H에서는 6개 기획 전부가 대칭 대조군을 이기고(짝지은 t 1.63~5.51),
  15m에서는 P4를 뺀 전부가 진다(t −3.06 ~ −15.61). 창을 통제해도 유지 — 봉의 효과다.
- **손절폭을 넓혀도 15m은 살아나지 않는다.** 1→4×ATR로 넓히면 비용 비중과 초과율은
  깨끗해지지만 기대값은 −0.131 → −0.138로 더 나빠진다.
- **최근 19개월이 순위를 뒤집는다.** 전 구간 1·2위(P6·P4)가 3구간에서 부호 역전.
  세 구간 모두 대조군 우위인 것은 P5 · P1 · P2 · P3뿐이고, 이 중 하방 고정을 지키면서
  유의한 것은 **P5 · P1**이다.
- 적용 검토 순위: **P5 → P1 → P2(조건부) → P6(보류) → P4(보류)**, P3 기각.

리포트: `out/asym-report.html` · 실행 순서는 §5.
