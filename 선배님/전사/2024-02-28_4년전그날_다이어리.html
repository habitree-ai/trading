쓰는 법 — 오른쪽 칸의 글이 판독 초안이다. 손글씨가 날림이라 [?] 로 표시한 곳은 확신이 없는 낱말이고, 아예 못 읽은 곳은 [판독 불가] 다. 이미지를 클릭하면 2배로 커진다.
  1. 칸을 고치면 브라우저에 즉시 임시 저장된다(위 상태 표시가 노랗게 바뀜). 창을 닫아도 남지만, 파일에는 아직 반영되지 않은 상태다.
  2. HTML 저장(또는 Ctrl+S)을 누르면 고친 내용이 든 같은 이름의 HTML 이 내려받아진다. 그 파일로 선배님/전사/ 의 이 파일을 덮어쓰면 파일이 정본이 된다. 다음에 열 때 임시본과 파일 중 새것을 자동으로 쓴다.
  3. 상태 칸은 판독 초안 → 확인함 / 직접 작성 으로 바꿔 두면 어디까지 봤는지 남는다. 초안으로 되돌리려면 카드의 초안으로 버튼.
  4. 3번·8번은 네이버 원본 주소가 404 라 수집본이 없다. 블로그에서 보이면 저장해 카드에 적힌 파일명으로 두면 자동으로 뜬다. 안 보이면 칸을 비워 두거나 직접 적는다.
판독 초안은 2026-09-05 에 수집본 6장(900×1200)을 2배 확대해 읽은 것이다. 선배님 본문의 문단(각 이미지 바로 뒤에 붙은 글)은 아카이브 원문에서 옮겼다. 다이어리 속 숫자·이름은 판독이 틀릴 수 있으니 원본 이미지를 우선한다.
